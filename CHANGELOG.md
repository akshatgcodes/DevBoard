## [0.1.0] — 2026-10-29

### ✨ Added
- GitHub OAuth login with a signed session cookie, plus a dev login by username
- GitHub contribution calendar (GraphQL with OAuth, public events API otherwise)
- LeetCode solved counts by difficulty and submission calendar
- Streak risk engine: streak ends today, week-over-week decline, flatline, projected stop
- Daily goals with a target per day, progress logging, 7-day history and streaks
- React dashboard with risk banner, stat cards, SVG heatmaps, LeetCode card and goals widget

### 🧪 Tests
- Unit tests for every risk rule and API tests for auth, goals, access control and the dashboard
